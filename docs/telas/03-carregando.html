Os quatro estágios
  • 0–3s — nada aparece. Só o botão em "Entrando…". Espera curta não merece tela cheia.
  • 3s — a cafeteira entra. "Preparando tudo para você."
  • 10s — o texto muda. Provar que o sistema está vivo é o que segura a pessoa.
  • 25s — assume que está devagar e oferece saída.
  • 45s — falha honesta, com o caminho de volta.
