A tela ainda funciona como uma ferramenta de decisão interna. O guia final deve apresentar a marca aprovada, regras de uso e aplicações reais.

### [P1] Tornar a opção aprovada inequívoca

As três opções têm peso visual semelhante, embora uma esteja marcada como escolha. A versão oficial precisa ser claramente distinguida.

### [P2] Incluir aplicações reais

Adicionar cabeçalho, avatar, favicon, tela de login e uso em fundo escuro, especialmente no tamanho de 20px.

### [P2] Avaliar a tipografia da marca

Verificar se a tipografia expressa memória e registro com personalidade suficiente.

### [P2] Rever elevação das superfícies

Escolher entre borda definida ou sombra discreta para evitar aparência genérica.
